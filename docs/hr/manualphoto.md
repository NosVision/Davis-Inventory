# รายการรูปภาพประกอบคู่มือระบบ HR (manualphoto)

> รายการรูปทั้งหมดที่ต้องแคปหน้าจอ เพื่อใส่ในคู่มือ **"ระบบ HR"** บนหน้าเว็บ `/guide`
>
> **ขั้นตอนของคุณ**
> 1. แคปหน้าจอตามคอลัมน์ "ต้องแคปหน้าจอไหน" และตั้งชื่อไฟล์ตามคอลัมน์ "ชื่อไฟล์รูป" ให้ตรงเป๊ะ
> 2. อัปโหลดขึ้น Supabase Storage เอา public URL มาวางในคอลัมน์ **URL**
> 3. บอกผมว่า "อัปเดตรูปคู่มือ HR แล้ว" ผมจะนำ URL ไปใส่ใน `manual-images.ts` ให้ (แก้ไฟล์เดียว รูปขึ้นทั้งคู่มือ)
>
> จนกว่าจะมี URL คู่มือจะแสดงกล่อง placeholder ประๆ พร้อมชื่อไฟล์ตรงตำแหน่งรูป — ระบบไม่พังและใช้งานได้ปกติ
>
> **ไม่ต้องทำครบ 129 รูปในครั้งเดียว** ทยอยทำได้ พออัปรูปไหนรูปนั้นขึ้นทันที

### ทำแค่ไหนดี?
- ⭐ **แถวที่มีดาว = รูปภาพรวม "ควรทำก่อน" (รวม ~37 รูป)** — ทำแค่ชุดนี้ก่อนก็ครอบคลุมทุกหน้าแล้ว 1 รูป/หน้า
- แถวที่เหลือ = รูปเจาะรายละเอียด (หน้าต่าง/สถานะ/ตัวอย่าง) ทำเพิ่มทีหลังได้ตามสะดวก

> อัปเดตอัตโนมัติจากเนื้อหาคู่มือจริง · หัวข้อในตารางเรียงตามลำดับหัวข้อในหน้า `/guide`
