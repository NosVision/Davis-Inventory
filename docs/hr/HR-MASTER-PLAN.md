## ✅ ปิดแล้วทุก decision

- **SV เข้าฐานภาษี + ปกส. ไหม? → ไม่เข้า (เงินเดือนอย่างเดียว)** — ยืนยันจากสูตรจริงไฟล์ พ.ค. 2026:
  `SS5% = IF(เงินเดือน≥17,500, 875, เงินเดือน×5%)` (ฐาน = SALARY เท่านั้น) · `Net = Total − SS5 − SS3 − ภาษี` โดย `Total` ไม่มี Service · Service เป็นคอลัมน์แยก (BR) จ่ายวันที่ 15
  → สลิปสิ้นเดือน "แสดง" salary+SV รวม แต่ "ฐานคำนวณ" ภาษี/ปกส./net ใช้เงินเดือนอย่างเดียว

## Phase 1 — Payroll engine ให้ถูก (foundational)

- [ ] **SV เป็นการจ่ายแยก**: engine ไม่บวก SV เข้า salary net transfer; SV มีไฟล์โอนของตัวเอง (จ่าย 15); สลิปสิ้นเดือนโชว์ SV ไว้ดู; ดึง SV กอง **N−1** (แก้ off-by-one `payruns/route.ts:243`)
- [ ] ฐานภาษี+ปกส. = เงินเดือนอย่างเดียว (Service ไม่เข้าฐาน) — ยืนยันจากสูตรไฟล์จริง `SS5%=IF(SALARY≥17500,875,SALARY×5%)`
- [ ] SSO คิดจากยอด prorate (ไม่ใช่เรตเต็ม) — ตรงเอกสาร §4.1 (`payroll.ts:324`)
- [ ] WHT/SS3% ฐาน = Total หลังหัก — เอกสาร §4.2 (`payroll.ts:346-349`)
- [ ] บังคับ SS5 หรือ SS3 อย่างใดอย่างหนึ่ง (เอกสาร §4.2)
- [ ] holiday comp = บรรทัดกรอกมือ (ดุลพินิจ เอกสาร §3.4) — ไม่ auto
- [ ] worked_days นับวันที่ HR override ด้วย (`payruns/route.ts:408`)
- [ ] prorate = calendar (ค่าปัจจุบัน) — ตาม Q4

## Phase 2 — หน้ารวม SV + เงินเดือน `/hr/close`

- [ ] route `/hr/close?month=` — Timeline 11 ขั้น + ตารางกระทบยอดรายคน (ตาม mockup)
- [ ] month rhythm: 1–15 ปิด SV · 16–25 รอปิดรอบ · 26–29 ทำเงินเดือน+ส่งบัญชี · 30/31 ปิดยอด+จ่าย

## Phase 3 — ตาราง (HQ จัด)

- [ ] role/permission **"HQ ผู้จัดตาราง"** แยกจาก HR (เข้าหน้าจัดตารางทุกร้านได้ แต่ไม่ได้สิทธิ์ HR เต็ม)

## Phase 4 — ประเมินต่อสาขา (เต็ม)

- [ ] flow มอบหมาย: **เลือกสาขา → เลือกกลุ่มผู้ถูกประเมิน → เลือกผู้ประเมิน (กรองตำแหน่ง) → เลือกหัวข้อ**
- [ ] เก็บ `store_id` ตอนมอบหมาย + กรอง candidate dropdown ตามสาขา (เลิก flat 50)
- [ ] ให้ผู้จัดการสาขามอบหมายได้ (ไม่ใช่แค่ HR/owner)
- [ ] เชื่อม `hr_eval_period_stores` (หรือถอดทิ้ง) ให้ scope งวดต่อสาขาใช้งานได้
- [ ] **แจ้งเตือนผู้ประเมินเมื่อได้รับมอบหมาย** (ยังไม่มี)
- [ ] เพิ่ม close-gate: คำนวณ/จ่าย payout เฉพาะหลังปิดงวด + กัน stale
- [ ] gate การมองเห็นคะแนน: พนักงานเห็นหลังปิดงวด (ก่อน 15, ก่อน SV) — Q13
